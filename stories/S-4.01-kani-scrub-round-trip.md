# S-4.01: Kani proof — `unscrub(scrub(x, map), map) == x`

## Narrative

- **As a** compliance reviewer evaluating otsniff's privacy claims
- **I want** a Kani proof that the scrub round-trip is exact for any
  bounded input string under any deterministic pseudonym map
- **So that** the privacy claim isn't a sentinel-on-one-fixture argument

## Acceptance Criteria

### AC-001 (BC-5.01.003 proven)
- A Kani harness in `kani-proofs/scrub_roundtrip.rs` (or
  `src/scrub.rs::kani_harnesses`) proves: for any input `s` of length
  ≤ N bytes and any map `m` with M ≤ K entries, `unscrub(scrub(s, m), m) == s`.
- Bounds N and K are documented and chosen to balance proof time vs
  generality. Initial: N = 32, K = 4.
- **Test:** `cargo kani --harness scrub_roundtrip` proves the property.

### AC-002 (CI integration)
- Kani proofs run on a slow schedule (weekly) in
  `.github/workflows/kani.yml`. Failure opens an issue.

### AC-003 (proof documentation)
- `docs/proofs/scrub-roundtrip.md` documents the harness, the bounds,
  and why those bounds are appropriate evidence for the unbounded claim.

## Edge Cases

| ID | Scenario | Expected Behavior |
|----|----------|-------------------|
| EC-001 | Empty input | Round-trip holds trivially |
| EC-002 | Pseudonym collides with real-looking substring | Kani must explore this; if proof fails, scrub has a real bug |
| EC-003 | Non-UTF8 bytes | scrub_text operates on &str so non-UTF8 doesn't reach it; document |
