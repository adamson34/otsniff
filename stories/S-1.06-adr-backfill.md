# S-1.06: Backfill ADR-0008 through ADR-0012 for implicit architectural decisions

## Narrative

- **As a** future contributor wondering "why is there no async runtime here?"
- **I want to** find a numbered ADR with the original reasoning
- **So that** I don't re-litigate the decision from scratch

## Acceptance Criteria

### AC-001 (ADR-0008: no async runtime)
- `docs/adr/0008-sync-no-async-runtime.md` exists.
- Cites: single-threaded pipeline, no concurrent I/O, simpler dependency
  graph, no Tokio in the dependency tree, single-binary distribution.
- Status: Accepted. Date matches commit date.

### AC-002 (ADR-0009: drop ephemeral src_port from flow key)
- `docs/adr/0009-logical-flow-key.md` exists.
- Cites: SPAN captures show high-cardinality src_port noise; logical
  flow groups are what an analyst cares about; `flows: BTreeMap<(SocketAddr,Ip,Port,Proto), ...>`
  in `observe.rs`.

### AC-003 (ADR-0010: roll up plaintext-cred findings by kind)
- `docs/adr/0010-cred-finding-rollup-by-kind.md` exists.
- Cites: 4SICS-22 produced 12 Telnet duplicates; one finding per kind
  with destinations as evidence; the shipped P0-1 work in v0.2.

### AC-004 (ADR-0011: pulldown-cmark with raw-HTML event filter)
- `docs/adr/0011-pulldown-cmark-with-raw-html-filter.md` exists.
- Cites: AI responses are untrusted markdown; raw HTML events stripped;
  XSS sentinel test `ai_response_with_html_tags_does_not_emit_raw_html`.

### AC-005 (ADR-0012: audit log auto-derives path from -o)
- `docs/adr/0012-audit-log-auto-derives-path.md` exists.
- Cites: `<report-stem>.audit.json` default; `--audit-log` override; the
  decision to make audit a first-class artifact when `--ai` is set.

### AC-006 (ARCH-INDEX updated)
- `.factory/specs/architecture/ARCH-INDEX.md` ADR catalog table marks
  ADR-0008..0012 as `Accepted` (no longer `proposed`).
