# S-1.02: Recount BC confidence summary to match actual row tags

## Narrative

- **As a** spec reader counting BC coverage
- **I want to** see confidence totals that sum to 60
- **So that** the table is internally consistent

## Acceptance Criteria

### AC-001 (traces to ASR-002)
- The `## Confidence summary` table sums to exactly 60 (the documented BC total).
- HIGH / MEDIUM / LOW counts are derived from a direct `grep` of `(HIGH)` /
  `(MEDIUM)` / `(LOW)` markers in BC-INDEX rows, not from prior pass files.
- The 3 unnumbered "LOW gaps" (open-question placeholders) are documented
  separately as "Open question BCs" outside the 60-count tally.
