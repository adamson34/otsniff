# S-6.02: `otsniff diff` subcommand + delta computation

## Narrative

- **As an** OT defender comparing this quarter's capture to last quarter's
- **I want** `otsniff diff baseline.pcap suspect.pcap` to emit a delta
  report (HTML or markdown) listing what changed
- **So that** "what's new since last scan?" has a one-command answer

## Acceptance Criteria

### AC-001 (BC-9.05.001 — subcommand exists)
- `otsniff diff <baseline-pcap> <current-pcap> --baseline-map <path>
  --current-map <path> -o <out.html|md>` parses and routes.
- Subcommand is documented in `--help` and `docs/USAGE.md`.

### AC-002 (BC-3.08.001 — new hosts / disappeared hosts)
- `Diff` data structure contains:
  - `hosts_new: Vec<Asset>`
  - `hosts_gone: Vec<Asset>`
- Identification uses pseudonym IDs (from merged maps), not raw IPs.
- **Test:** Synthetic fixture: baseline has hosts {A,B}; current has
  hosts {B,C}; diff reports A gone, C new.

### AC-003 (BC-3.08.002 — finding deltas)
- `findings_new: Vec<Finding>`, `findings_recurring: Vec<Finding>`,
  `findings_resolved: Vec<Finding>`.
- Matching is by `(rule_id, src_pseudonym, dst_pseudonym, dst_port)`
  tuple; near-matches are not joined.
- **Test:** Fixture covering each category.

### AC-004 (BC-3.08.003 — role / flow shifts)
- `role_shifts: Vec<(Pseudonym, OldRole, NewRole)>` lists hosts whose
  role inference changed.
- `flow_shifts: Vec<FlowDelta>` lists new flow pairs and traffic-volume
  shifts above a configurable threshold (default 2×).

## Edge Cases

| ID | Scenario | Expected Behavior |
|----|----------|-------------------|
| EC-001 | Baseline and current have no shared hosts | All hosts in current are `hosts_new`; all hosts in baseline are `hosts_gone` |
| EC-002 | Maps do not share any pseudonyms | Treat as if S-6.01's merge step was skipped: warn and proceed with empty intersection |
| EC-003 | Finding rule_id was removed from current build | Treat as `findings_resolved` only if rule existed in baseline catalog |
| EC-004 | Pseudonym counter overflow when merging large maps | Document; switch to wider integer type if hit |
