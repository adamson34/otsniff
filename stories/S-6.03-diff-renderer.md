# S-6.03: HTML + markdown rendering for the diff report

## Narrative

- **As an** analyst opening the diff report
- **I want** clear sections for new, resolved, and recurring findings,
  plus host appearance/disappearance and role/flow shifts
- **So that** the longitudinal delta is readable at a glance

## Acceptance Criteria

### AC-001 (BC-8.04.001 — HTML diff renderer)
- `render_diff_html(diff: &Diff) -> Result<String>` produces a
  self-contained HTML report with sections:
  - Summary banner (counts of new/recurring/resolved findings, new/gone hosts)
  - New findings (rendered like existing findings, with "NEW since baseline" badge)
  - Resolved findings (rendered with strikethrough or "RESOLVED" badge)
  - Recurring findings (rendered with a "recurring" badge + first/last seen timestamps if available)
  - Host changes (new / gone)
  - Role shifts table
  - Flow shifts table (only entries above the 2× threshold)
- **Test:** Snapshot test in `tests/snapshot.rs` using insta.

### AC-002 (markdown renderer)
- `render_diff_markdown(diff: &Diff) -> String` produces the same
  content in markdown form, suitable for posting to issue trackers.
- **Test:** Snapshot.

### AC-003 (deterministic output)
- All sections sort deterministically. Same inputs produce byte-identical output.
- **Test:** Run renderer twice on the same `Diff`; assert equal.
