# S-2.06: `compat.ntlmv1` — NTLMv1 authentication detection

## Narrative

- **As an** OT defender on a network that still uses NTLMv1 over SMB/HTTP
- **I want** otsniff to flag NTLMSSP NEGOTIATE messages with
  `NTLMSSP_NEGOTIATE_NTLM` set and `NTLMSSP_NEGOTIATE_NTLM2_KEY` unset
- **So that** dictionary-attackable NTLMv1 is visible the same way
  SMBv1 and stale TLS already are

## Acceptance Criteria

### AC-001 (BC-1.03.006 — NTLMv1 negotiation observation)
- `observe.rs` recognizes the `NTLMSSP` signature (`"NTLMSSP\0"`) inside
  SMB/HTTP/RPC payloads.
- Decodes the NEGOTIATE_MESSAGE flags field (offset 12, 4 bytes LE).
- Emits `NtlmEvent { src, dst, dst_port, version: V1 | V2 }` when
  V1-class flags are set.
- **Test:** Round-trip with raw byte fixture of an NTLMSSP NEGOTIATE.

### AC-002 (BC-3.04.004 — finding emission)
- `compat.ntlmv1` fires at severity High when any `NtlmEvent::V1` is observed.
- Rolls up by `(src, dst)` pair.
- **Test:** Snapshot test with synthetic fixture.
