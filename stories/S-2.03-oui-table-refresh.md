# S-2.03: Expand embedded OUI table from ~50 to ~3,000 OT-relevant entries

## Narrative

- **As an** analyst running otsniff on a real plant capture
- **I want** vendor inference to resolve names for any reasonably common
  industrial vendor (Siemens, Rockwell, Schneider, Mitsubishi, Yokogawa,
  Phoenix Contact, ABB, Beckhoff, Moxa, etc.) and the major IT vendors
  on the same network
- **So that** the asset inventory and finding evidence aren't a wall of
  bare MACs

## Acceptance Criteria

### AC-001 (table size)
- `src/oui.rs::OUI_TABLE` contains ≥ 3,000 entries, sorted by prefix
  for binary search.
- Each entry is `(prefix: [u8; 3], vendor: &'static str)`.
- **Test:** `assert!(OUI_TABLE.len() >= 3000);` plus a test that confirms
  `OUI_TABLE.is_sorted_by_key(|&(p, _)| p)`.

### AC-002 (build size impact bounded)
- Release binary size growth from this story is < 200 KB
  (compressed-string-table or array-of-tuples encoding, your choice).
- **Test:** `cargo bloat --release --crates` before/after; the
  `oui` symbol family change is reported in the PR body.

### AC-003 (curated, not full registry)
- The table includes the curated OT-vendor subset listed in the
  P0-6 ROADMAP rationale plus broader IT vendors that appear in OT
  networks (Cisco, Dell, HP, VMware, Microsoft, common NIC vendors).
- The selection criteria + the cutoff are documented in a header
  comment on `oui.rs` so future updates can replay the curation.

### AC-004 (lookup correctness, no regression)
- All existing OUI tests in `oui.rs::tests` still pass.
- A new test confirms 10 sampled real-world OT vendor MACs resolve to
  the expected vendor name.
- **Test:** `cargo test oui::` green.

## Edge Cases

| ID | Scenario | Expected Behavior |
|----|----------|-------------------|
| EC-001 | MAC prefix not in table | Return None (vendor display "Unknown") |
| EC-002 | Locally-administered MAC (lsb of first octet = 1) | Lookup returns None; rendering may flag it as "locally administered" (optional) |
| EC-003 | Table contains duplicate prefixes | Build-time test fails; impossible state |
