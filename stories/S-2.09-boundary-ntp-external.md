# S-2.09: `boundary.ntp_external` — OT host syncing time to public NTP

## Narrative

- **As an** OT defender enforcing boundary hygiene
- **I want** otsniff to flag OT hosts sending NTP queries to public
  NTP servers (parallel to `boundary.dns_resolver`)
- **So that** time-source boundary violations are visible

## Acceptance Criteria

### AC-001 (BC-1.05.003 / BC-3.05.004 — cross-zone NTP detection)
- New detector emits `boundary.ntp_external` at severity Medium when:
  - Source IP is inside `--ot-subnet`
  - Destination IP is outside the OT zone AND outside common-internal
    NTP servers (pool.ntp.org IPs need not be hardcoded; the predicate
    is "dst not in OT zone").
  - Protocol is udp/123.
- Reuses the existing `flows` map (no observer change).
- Rolls up by source host, listing distinct external NTP destinations.
- Evidence cap = 15 (sibling of `boundary.dns_resolver`).
- **Test:** Snapshot test with synthetic fixture.
