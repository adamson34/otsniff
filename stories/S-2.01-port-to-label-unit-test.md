# S-2.01: Unit-test the port-to-label table in `unexpected_label`

## Narrative

- **As a** maintainer who refactors `unexpected_label` later
- **I want** a unit test that locks the 11-row port→label mapping
- **So that** accidentally dropping a row trips CI

## Acceptance Criteria

### AC-001 (traces to BC-AUDIT-009)
- A `#[cfg(test)] mod tests` block in
  `src/findings/unexpected_protocols.rs` asserts one positive case per
  label in the actual table at `src/findings/unexpected_protocols.rs:38–55`.
  Real labels are: smtp, bittorrent, rtmp, apns, gcm, stun, sip, irc,
  openvpn, teamviewer, anydesk (11 labels). The expected assertions:
  - `unexpected_label(6, 25) → Some("smtp")`
  - `unexpected_label(6, 6881) → Some("bittorrent")` (range 6881..=6889)
  - `unexpected_label(17, 6881) → Some("bittorrent")` (UDP range)
  - `unexpected_label(6, 1935) → Some("rtmp")`
  - `unexpected_label(6, 5223) → Some("apns")`
  - `unexpected_label(6, 5228) → Some("gcm")` (range 5228..=5230)
  - `unexpected_label(17, 3478) → Some("stun")`
  - `unexpected_label(6, 5060) → Some("sip")` (also tested as 17/5060)
  - `unexpected_label(6, 6667) → Some("irc")`
  - `unexpected_label(6, 1194) → Some("openvpn")` (also tested as 17/1194)
  - `unexpected_label(6, 5938) → Some("teamviewer")`
  - `unexpected_label(6, 7070) → Some("anydesk")` (also 6568)
  - Negative cases: `unexpected_label(6, 23) → None`,
    `unexpected_label(6, 1234) → None` (telnet and unknown ports are
    NOT in this table — sentinels).
- **Test:** `cargo test --lib unexpected_protocols::tests` green.

### AC-002 (lock the size of the table)
- Test asserts the table returns `Some(_)` for exactly N distinct
  (proto, port) inputs where N matches the table row count documented
  in `METADATA.trigger`.
- **Test:** A test counts unique non-None outputs across a swept input space.
