# S-2.08: `creds.rdp_no_nla` — RDP without Network Level Authentication

## Narrative

- **As an** OT defender concerned about legacy RDP exposure
- **I want** otsniff to flag RDP connections negotiated without NLA
- **So that** weak-RDP exposure is reported alongside other cleartext-cred findings

## Acceptance Criteria

### AC-001 (BC-1.04.004 — RDP NLA-absent observation)
- `observe.rs` recognizes the X.224 Connection Confirm packet
  (TPKT version 3 + X.224 PDU type 0xD0) on tcp/3389.
- Decodes the optional `RDP_NEG_RSP` block to read `selectedProtocol`.
- Emits `RdpEvent { src, dst, selected_protocol }`.
- **Test:** Round-trip test with raw byte fixture (no-NLA case + NLA case).

### AC-002 (BC-3.04.006 — finding emission)
- `creds.rdp_no_nla` fires at severity Critical when
  `selected_protocol & 0x01 == 0` (PROTOCOL_RDP, no SSL/HYBRID/HYBRID_EX).
- Rolls up by `(src, dst)` pair.
- **Test:** Snapshot test.
