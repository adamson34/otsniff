## Implementation note

`src/observe.rs` was updated to accept LDAP on both tcp/389 and tcp/3268.
The check in the packet ingest loop reads:

```rust
if pkt.dst_port == ldap::PORT || pkt.dst_port == 3268 {
```

Additionally `classify_flow` was extended so that the flow label `"ldap-gc"` is
applied to port 3268 traffic in the comms matrix:

```rust
(Transport::Tcp, 3268) => "ldap-gc",
```

The finding layer treats both ports identically — a BindRequest on 3268
produces the same `creds.ldap_simple_bind` finding as one on 389.
